# Poker Arena

A responsive Texas Hold'em-style poker simulator built with React and JavaScript.

## Features

- Player vs Computer
- 52-card shuffled deck
- Texas Hold'em-style gameplay
- Check, Call, Raise and Fold
- Virtual chips and pot management
- Computer opponent with heuristic decision-making
- Bluffing and semi-bluffing
- Slow-play behavior
- Poker hand evaluation
- Showdown and tie detection
- All-in handling
- Game statistics
- Game history
- LocalStorage persistence
- Responsive UI

## Technologies Used
